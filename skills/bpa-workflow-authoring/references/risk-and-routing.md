# 风险与路由

## 风险分级

| 等级 | 典型能力 | 默认治理 |
|---|---|---|
| R0 | 纯计算、只读上下文 | 自动执行并留痕 |
| R1 | 更广只读、业务数据抽取 | 限域、限速、结果校验 |
| R2 | 可逆写入、导航、下载或上传 | 明确权限、前后验证 |
| R3 | 发布、改价、删除或不可轻易恢复的写入 | 动作前人工批准 |
| R4 | 资金、预算、退款或高影响决策 | 强人工控制与独立复核 |

Workflow 等级不得低于任一引用 Node。风险不确定时取更高等级。

## 结果路由

| 结果 | 默认处理 |
|---|---|
| `success` | 下一业务节点或 `control.succeed` |
| `failure` | 有业务兜底则进入兜底，否则 `control.fail` |
| `timeout` | 仅对声明的可重试错误有限重试，耗尽后失败 |
| `rejected` | 不重试、不进入失败或人工恢复路由；保留拒绝原因并以不可恢复的 `rejected` 终态结束，处理原因后新建 Run |
| `cancelled` | 停止后续动作并以取消结束 |
| `uncertain` | 不重试、不宣告成功，要求人工核验真实业务状态 |

不要用同一个通用成功终点吞掉异常语义。

## 条件 DSL

只允许：

```text
input.ready == true
input.shop.id != null
previous.supported == true
previous.count == 0
```

不允许函数、算术、正则、数组脚本、JavaScript 或页面提供的表达式。
