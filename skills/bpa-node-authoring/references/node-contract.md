# Node 契约

## 必填内容

- 单一职责和稳定业务名称。
- 精确 SemVer；已发布版本不可覆盖。
- 输入、输出、配置 JSON Schema。
- 风险等级、权限、Browser Origin。
- 默认超时、是否可取消、幂等类别。
- 枚举错误码及其可重试性。
- 必需证据和成功判定。
- Adapter 或实现版本范围。

## 幂等类别

| 类别 | 说明 |
|---|---|
| `pure` | 相同输入产生相同结果，无外部副作用 |
| `repeatable_read` | 可重复读取，允许页面数据随时间变化 |
| `verified_write` | 写入前后都能验证，重复投递可识别已完成 |
| `non_repeatable` | 无法安全重复；中断后可能进入 `uncertain` |

## 最低契约测试

- 拒绝非法输入和非法输出。
- 超时和取消在每个等待边界生效。
- 重复 `idempotency_key` 不重复推进状态。
- 旧 `fencing_token` 被拒绝。
- 未声明权限、Origin 或页面上下文被拒绝。
- 所有错误码都有终态或明确路由。
- 页面结构变化不会退化成越权选择器。
