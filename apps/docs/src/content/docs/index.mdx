## 一条执行链路

```text
Operator Console / CLI / MCP
            │ bpa.control/hello/1
            ▼
        Local Core
            │
   Compiler → IR2 → Engine
            │ Runtime Invocation
            ▼
      Provider Registry
            │
 Browser Gateway ↔ Native Host ↔ Extension Bridge
            │
            ▼
      reviewed Adapter
            │
            ▼
   real browser page state

Every transition → Event · Evidence · Source · Asset · Audit
```

Workflow 决定流程结构；Node 描述单步能力；Adapter 保存平台页面逻辑；Engine
只推进确定性的执行状态。Workflow 不允许携带 selector、XPath、坐标或任意
JavaScript。

## 三条必须同时成立的边界

### 已审核能力

浏览器只执行 Extension Capability Manifest 中已经注册的精确 Node 和版本。
AI 可以创建 Candidate，但不能自行批准或发布正式资产。

### 冻结执行计划

Run 创建时保存规范化 IR2、摘要、风险快照和精确资产闭包。恢复使用保存的计划，
不会重新编译已经变化的源资产。

### 可验证结果

大型正文不进入控制协议或普通 Result。Evidence 先完成分块上传和摘要验证，
Result 才能引用它并推进 Engine。

## 当前不是哪些东西

- 不是可以执行任意网页脚本的通用 Agent。
- 不是用无头浏览器替代用户真实登录状态的采集器。
- 不是验证码、会员权限、限流或平台风控的绕过工具。
- 不是已经开放保存、发布、改价等 R2+ 写动作的系统。
- 不是云端、多租户或 PostgreSQL 部署。
